Model & methodology

1. Excel is now the data source

Use Load / Update Excel to replace the embedded dataset. The browser reads the first worksheet and recalculates the model. Required fields include Status, Name, Manager, Director, Cuenta, Mercado, Pais, Fecha implementación Datanitiv, # CE's and Wave migrada.

2. Migration Wave is a hard scope gate

If the wave contains No Migra, the person receives no GWS migration date, no Datanitiv acceleration recommendation and no migration action. Blank or conflicting wave assignments are classified as Review and are also excluded from automatic actions until corrected.

3. Retained No-Migrate holder

If an active No-Migrate AM shares an account with an AM who will migrate, the No-Migrate AM can act as retained TPS coverage. The migrating AM can therefore be released earlier under Fast-track/Balanced without creating a migration action for the retained person. This is shown explicitly, not hidden.

4. Unit of weight

Account weight is # CE's. Enterprise CE is de-duplicated at Country + Account. CE Exposure uses the full CE of every account the AM touches. Allocated CE divides CE across active assignees and remains only a workload proxy.

5. Baseline

An actionable active AM remains TPS-dependent until the latest Datanitiv date among all accounts assigned to them. GWS readiness = blocker date + selected stabilization buffer.

6. Fast-track

Retained No-Migrate holders are applied first. For remaining accounts with 2+ actionable active AMs, one temporary legacy holder is selected to minimize blocked-person-days. Co-assignees may move earlier.

7. Balanced

Same mechanism as Fast-track, but temporary legacy-held CE per migrating person is capped at . The cap is the rounded P90 exposure of the actionable population, not a staffing standard.

8. LOA

An AM on LOA cannot serve as active legacy coverage. If only one active actionable person remains, the account is treated as a hard blocker unless another active No-Migrate holder exists.

9. Date acceleration

Acceleration is evaluated by critical bundle. If several accounts share the same latest blocker date, moving only one may create zero GWS benefit. No-Migrate-only accounts never enter this recommendation table.

10. Limits

The model does not know GWS licensing, device policy, account contractual restrictions, TPS complexity, skill compatibility, Datanitiv UAT quality or actual workload beyond CE. These remain execution gates.
